# Team Logo Assets

Place optional PNG files in this directory using the exact filenames below:

```text
mi.png
csk.png
rcb.png
kkr.png
rr.png
pk.png
dc.png
lsg.png
```

The application will still run when these files are missing; it will display team abbreviations instead.

Only add logo assets that you are permitted to redistribute in your GitHub repository.
